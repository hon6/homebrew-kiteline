# Homebrew tap for Kiteline

[Kiteline](https://github.com/hon6/kiteline) is a phone remote for the coding agents already running on your computer: Claude Code, Codex, OpenCode and more, on your iPhone, iPad and Apple Watch.

```bash
brew install --cask hon6/kiteline/kiteline
```

Kiteline updates itself; `brew upgrade --cask kiteline` works too. The cask is updated automatically with every release. Then get Kiteline on your iPhone from the [App Store](https://apps.apple.com/app/id6825244029) and scan the pairing code shown on your Mac.

---
